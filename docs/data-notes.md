# 取数口径与数据质量说明

本文记录「从财报到 `data/companies.json`」过程中的所有口径决策、缺年补查、单位换算、已知偏差与抽样核对结果。目的是让每一个数字都能被追溯、被质疑。

---

## 一、字段口径

| 字段 | 口径 | 说明 |
|---|---|---|
| `rev` | 营业收入（合并报表） | 券商/银行/保险取**营业总收入**；其余取**营业收入**。金额单位统一为**亿元** |
| `np` | 归母净利润 | 归属于母公司所有者的净利润，已剔除少数股东损益 |
| `gm` | 销售毛利率（%） | 券商、银行、保险等无「成本」科目的公司为 `null`，页面显示「—」 |
| `listed` | 上市年份 | 纯年份（4 位），不含月日 |
| `coverage` | `[起始年, 结束年]` | 起始年 = 序列首个有完整 `rev` 与 `np` 的年度；结束年 = 最新年报年度 |
| `years[].y` | 自然年 | A 股年报口径（12 月 31 日），非单季、非财年 |

## 二、单位换算规则

同花顺接口返回的单位不统一，需在子任务内统一换算为**亿元（保留两位小数）**：

| 接口单位 | 处理 |
|---|---|
| 元 | 除以 1e8 |
| 万元 | 除以 1e4 |
| 亿元 | 原值 |
| 万亿元 | 乘以 1e4 |

典型事故：**中国石化**接口出现「万亿元」单位，若不换算会差 4 个数量级。合并脚本在读取 `tmp/batch*.json` 时已按亿元落库。

## 三、营业收入 vs 营业总收入

这是最容易踩的坑。同花顺的「营业收入」字段对券商/银行/保险类公司会**剔除利息净收入**，导致数字严重失真。

| 公司 | 情况 | 处理 |
|---|---|---|
| 东方财富 | 接口「营业收入」2024 年约 31 亿，实际营业总收入约 116 亿 | 改用营业总收入 |
| 保利发展 | 营业收入与营业总收入差异较小，但为与地产行业可比 | 采用营业总收入 |
| 中信证券 / 招商银行 / 中国平安 | 金融口径 | 采用营业总收入（或对应「营业总收入」字段） |

## 四、缺年与补查

同花顺对早期年份（尤其 1999、2006、2009、2016、2019 附近）常缺少年报行。规则：

1. **禁止插值**。缺年宁可序列断开或从有数据的年份起算，不伪造中间值。
2. **逐年补查**。发现缺年先按单年重查，仍无则记录在 `note`。
3. **覆盖率下降要说明**。若补查后起始年右移，`coverage[0]` 随之更新。

已处理的缺年案例：

| 公司 | 缺年 | 处理 |
|---|---|---|
| 泸州老窖 | 2000–2003、2021、2022 | 逐年补查补齐 |
| 福耀玻璃 | 1994 及之前毛利率 | 毛利率仍缺失，`gm: null` |
| 长城汽车 | 2003、2004 三项指标全空 | 合并时剔除，`coverage` 从 2005 起 |

## 五、不可比断点

以下情况序列会「断」，跨断点算增速会得出错误结论：

| 类型 | 公司案例 | 处理 |
|---|---|---|
| 会计差错更正 | 五粮液 2025（前三季度营收追溯下调 300 亿） | 序列保留，note 注明不可直接连线 |
| 会计准则切换 | 中国平安 2023（IFRS17） | 红旗标注断点年份 |
| 资产注入 | 长江电力 2010/2016/2023 | 红旗单列断点年份 |
| 借壳上市 | 顺丰控股、分众传媒 | 序列从借壳后首个完整年度起 |

## 六、抽样核对

用同花顺公告检索，把公司 2025 年报原文的关键数字与 `data/companies.json` 最新年度比对。抽样原则：跨行业、跨引擎各取 1–2 家，优先覆盖「已知口径陷阱」的公司。

### 第一批核对（2026-11-08，4/38 家，约 10.5%）

| 公司 | 字段 | 数据值 | 年报原文 | 结论 |
|---|---|---|---|---|
| 中国石化 | 营业收入 | 27836.0 亿 | 2,783,583 百万元 = 27,835.83 亿 | ✅ 一致；摘要「2,783.6 亿元」为笔误，实为 2.78 万亿元 |
| 中国石化 | 归母净利 | 318.09 亿 | 31,809 百万元 = 318.09 亿 | ✅ 一致 |
| 招商银行 | 营业收入 | 3375.32 亿 | 3,375.32 亿 | ✅ 一致 |
| 招商银行 | 归母净利 | 1501.81 亿 | 1,501.81 亿 | ✅ 一致 |
| 中远海控 | 营业收入 | 2195.04 亿 | 219,503,805,222.70 元 = 2,195.04 亿 | ✅ 一致 |
| 中远海控 | 归母净利 | 308.68 亿 | 308.68 亿 | ✅ 一致 |
| 药明康德 | 营业收入 | 454.56 亿 | 45,456.2 百万元 = 454.56 亿 | ✅ 一致 |
| 药明康德 | 归母净利 | 191.51 亿 | 19,194.9 百万元 = 191.51 亿 | ✅ 一致 |

**结论**：4 家 8 项核心数字零误差。其中中国石化验证了「万亿元」单位陷阱——年报摘要写「2,783.6 亿元」是笔误（应为 2.78 万亿元），我们的换算口径正确。

## 八、跨市场取数

港股/美股中概样本（腾讯、阿里、美团、拼多多、京东、小米）取 2021–2025 五年快照，对齐「最近五年商业模式变迁」诉求。

| 规则 | 说明 |
|---|---|
| 币种 | 中概以人民币记账，接口返回「记账本位币」，统一换算亿元 |
| 财年 | 阿里为财年（4 月–次年 3 月），接口把 FY 标注为财年结束日历年，`note` 说明 |
| 累计 vs 年度 | 接口返回累计口径（Q1/H1/9M/FY），年度值取 12-31 行 |
| 美团 2025 亏损 | GAAP 净亏 233.54 亿已与年报原文核对属实，主因 AI 投入、海外 Keeta 扩张、销售及营销开支同比增约 389 亿；经营亏损 250 亿 |
| 京东 2024 高基数 | 2024 年净利 413.59 亿含一次性投资收益，2025 年 196.31 亿为口径回归 |

## 九、估值与金融指标

- 估值：抽样 5 家（茅台/招行/神华/中远海控/宁德）2025-12-31 的 PE(TTM)/PB/股息率 TTM 时点快照；历史分位待补。
- 金融指标：招商银行（净息差/不良率/成本收入比/拨备覆盖率/加权 ROE）、中国平安（NBV/内含价值/NBV 率）各取 2021–2025 年度。

## 十、第四批取数（8 个空白行业，20 家）

2026-11 补钢铁、计算机、通信、国防军工、社会服务、环保、美容护理、纺织服饰八个申万一级行业，共 20 家，403 个财年。子任务隔离取数（3 组并行），主任务统一写判断。

| 行业 | 公司 | 覆盖 | 关键口径处理 |
|---|---|---|---|
| 钢铁 | 宝钢、中信特钢、华菱 | 1997/1999/2000–2025 | 宝钢 2005 集团注入；中信特钢 2019 兴澄借壳（营收 126→726 亿）；华菱 2004 湘钢涟钢注入 |
| 计算机 | 金山办公、科大讯飞、用友网络 | 2001/2008/2019–2025 | 用友 2013 毛利率台阶式下降（实施服务并入）；讯飞项目制应收高 |
| 通信 | 中兴、中国联通、中天科技 | 1997/2002–2025 | 联通 2008 CDMA 出售一次性收益使净利虚高；中兴 2018 禁令亏损 -69.84 亿 |
| 国防军工 | 中航沈飞、中航光电、航发动力 | 1996/2007–2025 | 沈飞 2017 重组（原中航黑豹）；航发 2008/2014 两次注入 |
| 社会服务 | 中国中免、宋城演艺 | 2009/2010–2025 | 中免 2018 日上并表、2020 剥离旅行社；宋城 2020/2022/2023 亏损 |
| 环保 | 伟明环保、瀚蓝环境 | 2000/2015–2025 | 伟明 2023 并表印尼镍；瀚蓝 2014 创冠中国并表，2010 净利含 4.4 亿非经常性损益 |
| 美容护理 | 珀莱雅、贝泰妮 | 2017/2021–2025 | 珀莱雅毛利率逆势升至 73%；贝泰妮 2025 增收不增利 |
| 纺织服饰 | 海澜之家、华利集团 | 2000/2021–2025 | 海澜 2014 借壳（原凯诺科技）；华利 2025 毛利率下滑 4.9pct |

**断点处理原则**：借壳/资产注入一律以「注入后首个完整年度」为序列起点，或保留但用红旗标注断点年份，跨断点不计算 CAGR。亏损年保留负值，不做平滑。
