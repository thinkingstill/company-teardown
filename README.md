# A股上市公司商业模式拆解

按「**服务领域 × 货币化引擎 × 付费对象 × 时间**」四条轴，把 A 股公司从上市那一年起拆到最新年报：钱从哪来、凭什么能收这个价、谁最终掏钱、这十几年变了什么。

在线查看（GitHub Pages，启用后生效）：**https://thinkingstill.github.io/company-teardown/**

本地查看：`python3 scripts/build_site.py && python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`（`index.html` 由脚本从 `data/companies.json` 生成，未入库）。

## 怎么看

左侧选公司，右侧是拆解。每一页固定六块：

| 区块 | 回答的问题 |
|---|---|
| 一句话结论 | 这家公司此刻的处境，以及什么情况下这个判断会失效 |
| 四个指标 | 最新营收、最新净利、上市以来营收 CAGR、最新毛利率 |
| 上市以来曲线 | 营收（柱）+ 归母净利（线），一眼看出增长是不是有断点 |
| 收入结构 | 按引擎拆的收入占比，不是财报分部 |
| 四条轴 | 货币化引擎 / 定价权 / 付费对象 / 五年变迁 |
| 红旗与观察点 | 已触发的异常 + 需要盯住的领先指标 |

除了单家公司详情，还有三个视图与工具：

- **同赛道横比**：同行业 2–5 家并列营收、净利、CAGR、毛利率、净利率，并给出按引擎的差异归因。
- **年度横切面**：顶栏切换到某一年，看全样本的行业与引擎分布、盈利公司占比、营收增速最快/最慢的公司。
- **单家导出**：每家公司可一键导出 Markdown。
- **金融机构专用指标**：银行看净息差/不良率/拨备覆盖率/成本收入比，保险看新业务价值/内含价值/NBV 率，不与制造业混比毛利率。
- **估值与历史分位**：143 家覆盖 2021–2025 五个年度末的 PE(TTM)/PB/股息率（余 18 家取数未回，页面顶栏以「N 家待补估值」明示，不静默隐藏），并给出**百分位分位**（0%=五年最低，100%=五年最高）与双折线走势图。亏损公司不给 PE 分位（分母为负无意义），利润趋近零时 PE 作废（|PE|>300），引导看 PB。
- **口径一致性**：`scripts/check_valuation.py` 体检量级与跳变，`scripts/merge_valuation.py` 统一清洗与分位计算，异常值不会静默入库。

**同一引擎下的「变体」比引擎代码本身更有信息量。** 白酒三家都是 E3 商品自营，但茅台是「品牌 + 配额」、五粮液是「品牌 + 渠道推力」、泸州老窖是「品牌 + 大单品放量」，只数 E 代码会把它们误判为同质。因此 `scripts/check_coverage.py` 除 E 代码外还统计主轴里的副标签（品牌/渠道/制造/养殖/客运/装卸/时效/钾肥/煤化工……），31 个行业里机器、汽车、煤炭、钢铁四类属于「引擎天然单一」，其余行业都做到了 2 种以上引擎或变体。

### 怎么扩的

扩量不把大表格塞进主流程：**子任务批量取数 → 写 JSON → 主任务写判断 → 脚本合并校验**，多组子任务并行推进，财务序列留在子上下文中，主流程只收覆盖范围与异常。新增一家 = 补齐 `data/companies.json` 里的一段 JSON，跑一次 `build_site.py`。操作手册见 [`docs/expand.md`](docs/expand.md) 与 [`docs/data-notes.md`](docs/data-notes.md)。

**161 家不是终点**，是申万一级 31 个行业「每行业 5 家」这个密度目标达成后的规模点；下一步是把估值分位补齐到 161 家，再考虑行业内部按二级行业继续分层。

## 数据口径

- **来源**：上市公司年报（合并报表），经同花顺金融数据接口整理；上市日期取自交易所披露。
- **单位**：人民币亿元；毛利率为销售毛利率。港股/美股中概以人民币记账，已统一换算。
- **年度**：自然年，A 股年报口径（12 月 31 日），非单季；**阿里巴巴为财年（4 月–次年 3 月）**，页面标注 FY。
- **归母净利**：归属于母公司所有者的净利润，已剔除少数股东损益；美团 2025 年 GAAP 净亏损含 AI 与海外扩张投入，已标注。
- **结构占比**：除少数公司外，收入结构的细分为年报口径的近似拆分，页面标注「估算」。

### 必须知道的口径陷阱

1. **五粮液 2025 年**因收入确认方式调整做了会计差错更正，前三季度营收由 609 亿追溯下调至 306 亿。它与 2024 年及以前**不可直接连线**，页面已标注。
2. **招商银行 / 中信证券 / 中国平安**没有毛利率概念，营收口径与制造业不可横向比较；页面毛利率显示「—」。
3. **中国平安 2023 年**起执行新保险合同准则，营收口径与 2022 年及以前不可直接比较；利润主要由利差与死差决定。
4. **万华化学**合并毛利率从 40% 降到 14%，一大半是低毛利的石化贸易业务占比上升造成的**结构稀释**，不等于聚氨酯主业盈利恶化——看主业要盯 MDI 价差。
5. **东方财富**接口的「营业收入」会剔除利息净收入，2024 年仅约 31 亿，而营业总收入约 116 亿——已改用**营业总收入**口径。
6. **洛阳钼业**合并收入含大量低毛利贸易业务，矿山利润被稀释；看主业要拆开 IXM 贸易与矿山自产。
7. **顺丰控股 / 分众传媒**为借壳上市，借壳前的会计主体不是现有经营主体，序列从借壳后首个完整年度起。
8. **长城汽车** 2003、2004 年三项核心指标缺失，序列从 2005 年起；**中国石化**接口出现「万亿元」单位，已统一换算为亿元。
9. **药明康德 2025 年**净利率异常抬升含大额非经常性损益，主业经营要盯扣非口径，不能把一次性收益当成经营改善。
10. **长江电力** 2010、2016、2023 年三次资产注入造成营收断点。跨断点算增速会得出「高增长」的错觉，真实增长看单位装机发电量。
11. **总额法 vs 净额法**：重庆百货 2019 年营收到 345 亿、2020 年又回到 211 亿；天虹 2020 年营收从 194 亿降到 118 亿而毛利率从 28.6% 跳到 42.9%——都是收入确认方式变了，不是经营突变。两家均已标注。
12. **并表断点**：中直股份 2013 年、龙佰集团 2016 年（钛白粉资产注入）、中国重工 2011 年、恒力石化 2016 年（借壳大橡塑），跨断点算 CAGR 会失真。
13. **中国重工 2025 年**被中国船舶吸收合并退市，序列止于 2024；接口对 2025 年仍会返回一套恒定值，已判为失效未采用。
14. **中国国航** 2020–2025 连续六年归母亏损（累计约 727 亿），2022 年毛利率 -56.55% 是收入 529 亿不足以覆盖固定成本时的极端值，不具可比性；判断这类公司看座公里收益与客座率，不看毛利率。
15. **锦江酒店** 毛利率 89.89%（2019）→ 25.74%（2020），是并购（丽笙等）叠加新收入准则净额法的双作用，不是成本失控。
16. **亚泰集团 / 中信国安 / 南京高科 / 悦达投资** 是综合类控股平台，合并报表混合了建材、地产、医药、投资等互不相关的主业，合并净利不反映任何单一主业的经营质量，要看分部资产重估。
17. **估值取数的 PB 列陷阱**：同花顺接口在 query 写「市净率PB（倍）」时，仍可能返回「市净率(中证发布)（单位：%）」这一列，数值与市值/净资产口径相差 5–8%。解析时必须**逐行按所属表头**判断列义，遇到中证发布口径一律置空而非强行换算；同一批多次返回的列序还会变化，不能按固定下标取列。
