# A股上市公司商业模式拆解

按「**服务领域 × 货币化引擎 × 付费对象 × 时间**」四条轴，把 A 股公司从上市那一年起拆到最新年报：钱从哪来、凭什么能收这个价、谁最终掏钱、这十几年变了什么。

在线查看：打开 `index.html`（单文件，无依赖，双击即可），或访问 GitHub Pages。

---

## 怎么看

左侧选公司，右侧是拆解。每一页固定六块：

| 区块 | 回答的问题 |
|---|---|
| 一句话结论 | 这家公司此刻的处境，以及什么情况下这个判断会失效 |
| 四个指标 | 最新营收、最新净利、上市以来营收 CAGR、最新毛利率 |
| 上市以来曲线 | 营收（柱）+ 归母净利（线），一眼看出增长是不是有断点 |
| 收入结构 | 按引擎拆的收入占比，不是财报分部 |
| 四条轴 | 货币化引擎 / 定价权 / 付费对象 / 五年变迁 |
| 红旗与观察点 | 已触发的异常 + 需要盯住的领先指标 |

## 覆盖范围

**v1 批次：8 家，7 个行业，155 个财年。**

| 公司 | 行业 | 上市 | 覆盖 |
|---|---|---|---|
| 五粮液 | 食品饮料 | 1998 | 1998–2025（28 年） |
| 恒瑞医药 | 医药生物 | 2000 | 2000–2025（26 年） |
| 贵州茅台 | 食品饮料 | 2001 | 2001–2025（25 年） |
| 招商银行 | 银行 | 2002 | 2002–2025（24 年） |
| 海康威视 | 电子 | 2010 | 2010–2025（16 年） |
| 比亚迪 | 汽车 | 2011 | 2011–2025（15 年） |
| 美的集团 | 家用电器 | 2013 | 2013–2025（13 年） |
| 宁德时代 | 电力设备 | 2018 | 2018–2025（8 年） |

A 股现有 5,000 余家上市公司。**这不是全市场扫描，是一个可复制的样本批次**——每家都做到了「从上市首年到 2025 年」的完整序列、逐家写过判断，而不是套模板生成的简介。

### 为什么先做 8 家

财报序列要逐家取、逐家核口径，一家公司的完整历程（20+ 年、含分部与运营指标）需要 3–4 次结构化取数调用。8 家是"能保证每家都被真正分析过"的数量上限。

扩量的方式已经固化：新增一家 = 补齐 `data/companies.json` 里的一段 JSON（约 60 行），跑一次 `build_site.py`。操作手册见 [`docs/expand.md`](docs/expand.md)。

## 目录结构

```
.
├── index.html              # 单文件查看器（数据已内联，可直接分发）
├── data/
│   ├── companies.json      # 主数据源（唯一需要编辑的文件）

├── scripts/
│   ├── build_site.py       # 注入数据 → 生成 index.html + 拆分文件
│   └── validate.py         # schema / 年份连续性 / 口径 / 文本质量校验
├── docs/
│   ├── methodology.md      # 四轴框架与 A 股适配的引擎分类
│   └── expand.md           # 如何新增一家公司
└── PROJECT.md              # 批次看板与待办
```

## 数据口径

- **来源**：上市公司年报（合并报表），经同花顺金融数据接口整理；上市日期取自交易所披露。
- **单位**：人民币亿元；毛利率为销售毛利率。
- **年度**：自然年，A 股年报口径（12 月 31 日），非单季。
- **归母净利**：归属于母公司所有者的净利润，已剔除少数股东损益。
- **结构占比**：除少数公司外，收入结构的细分为年报口径的近似拆分，页面标注「估算」。

### 两个必须知道的口径陷阱

1. **五粮液 2025 年**因收入确认方式调整做了会计差错更正，前三季度营收由 609 亿追溯下调至 306 亿。它与 2024 年及以前**不可直接连线**，页面已标注。
2. **招商银行**没有毛利率概念，营收为「利息净收入 + 中间业务收入」，与制造业不可横向比较。
